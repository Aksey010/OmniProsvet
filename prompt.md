# Промпты для обработки материалов

Файл редактируется без правки кода. Плейсхолдеры: {i} {n} {source} {body} {files} {chunks} {parts} {count}.
Секции разделяются маркерами-комментариями — не удаляйте их.

<!-- ==== ФРАГМЕНТ ==== -->
Ниже — фрагмент {i}/{n} материала ({source}).

Сделай детальный конспект фрагмента:
- Выдели смысловые темы (работа, мероприятия, новости и анонсы, вакансии, обсуждения, личное и т.п.) и по каждой теме кратко и по существу изложи, что произошло или обсуждается.
- Отдельно выпиши извлечённые факты: даты, числа и суммы, имена, названия проектов и компаний, ссылки, места.
- Сжимай материал: не пересказывай каждое предложение и абзац — конспект должен быть примерно в 5-10 раз короче материала.
- Сохраняй только ключевые факты: даты и время, числа и суммы, имена, названия компаний и проектов, ссылки, места.
- Разделяй датированные факты (события, дедлайны, объявления) и нематериальные обсуждения (темы) — не смешивай.
- Дедупликация ссылок и контактов: каждую ссылку/контакт/ресурс упоминай ОДИН раз; при повторе — пропускай.
- Контакты не вываливай простынёй: группируй по компаниям/вакансиям/проектам и в таком порядке.
- Обрывки фраз и обрывки предложений не превращай в факты: либо не включай, либо явно помечай «(неполные данные)».

ФОРМАТ ВЫВОДА (строго): обычный текст для чтения в txt.
- Никакой markdown-разметки: без звёздочек (*), решёток (#), обратных апострофов, html-тегов, жирного и курсива.
- Никаких emoji и markdown-таблиц (строк с вертикальными чертами |): перечисления — только через дефис «- ».
- Тему обозначай строкой-заголовком с новой строки, например: ТЕМА: Работа
- По возможности пиши связным текстом (абзацами), как конспект для чтения; перечисления — через дефис «- » с новой строки.
- По-русски, сортировка по темам, только конкретика, без воды.

СТРОГИЙ РЕЖИМ ТОЧНОСТИ:
- Пиши ТОЛЬКО проверяемые факты из материала; никаких предположений, домыслов и обобщений «наверное».
- Точные даты, числа, суммы и имена переноси как есть — не «округляй» и не приукрашивай.
- Неполные факты помечай «(данных мало)» вместо додумывания.
- Каждый факт бери только из материала; ничего не добавляй от себя; не выдумывай.

# Материал
{body}

Детальный конспект фрагмента:

<!-- ==== ИТОГОВЫЙ ОТЧЁТ ==== -->
Ты составляешь ЕДИНЫЙ отчёт по всем обработанным материалам: {files} файл(ов), обработано {chunks} фрагментов в хронологическом порядке.

Требования:
- По-русски.
- Не пересказывай недосказанное как событие; если данных по пункту мало — так и пиши.
- Дедупликация: каждую ссылку/контакт/ресурс упоминай один раз; при повторе — пропускай.

ФОРМАТ ВЫВОДА (строго): plain text для чтения в txt-ридере.
- Никакого markdown: без решёток (#), звёздочек (*), подчёркиваний-выделений, html-тегов, жирного и курсива.
- Никаких emoji и markdown-таблиц (строк с вертикальными чертами |): перечисления — только через дефис «- ».
- Раздел обозначай строкой-заголовком с новой строки, заглавными буквами, например: КЛЮЧЕВЫЕ СОБЫТИЯ И ОБЪЯВЛЕНИЯ
- Между разделами — одна пустая строка.
- Внутри разделов по возможности монолитный связный текст абзацами; перечисления (события, факты, контакты) — через дефис «- » с новой строки.

СТРОГИЙ РЕЖИМ ТОЧНОСТИ:
- Пиши ТОЛЬКО проверяемые факты из конспектов; никаких предположений, домыслов и обобщений «наверное».
- Точные даты, числа, суммы и имена переноси как есть — не «округляй» и не приукрашивай.
- Неполные факты помечай «(данных мало)» вместо додумывания.

Структура ответа:

О ЧЁМ МАТЕРИАЛЫ
2-3 предложения по существу.

КЛЮЧЕВЫЕ СОБЫТИЯ И ОБЪЯВЛЕНИЯ
- Включай ТОЛЬКО датированные факты (реальные события, дедлайны, объявления с датой/сроком). Нематериальные обсуждения туда не попадают.
- Если у события нет явной даты — либо не включай, либо помечай «(данных мало)».
- Сортируй строго по дате, один порядок на весь блок.
- Повторяющиеся одинаковые события своди в один пункт с перечислением дат.
- один пункт = одно событие: дата — суть — место/формат — кто упоминал — важные детали.

ТЕМЫ И ОБСУЖДЕНИЯ
- Здесь только обобщения: мнения, повторяющиеся обсуждения, конфликты, договорённости без конкретной даты.
- Датированные факты сюда не включай — они живут в «Ключевых событиях».

ИЗВЛЕЧЁННЫЕ ФАКТЫ: ДАТЫ, ИМЕНА, СУММЫ, ССЫЛКИ
- Дедупликация: каждую ссылку/канал/контакт упоминай один раз.
- Контакты и ссылки группируй по компаниям/проектам/темам — не вываливай простынёй.
- Если не понятно, к чему контакт относится, ставь «(отнесение неясно)» вместо догадок.

# Конспекты фрагментов
{parts}

Единый отчёт:

<!-- ==== КАРТИНКИ ==== -->
К тебе приложены {count} картинок.

Задача — ТОЛЬКО OCR: извлечь видимый текст. Что изображено на картинке, не описывай и не комментируй — содержимое сцены не нужно.

Для каждой картинки по порядку:
- Перепиши весь видимый текст полностью и дословно: даты, имена, номера, суммы, контакты, ссылки, штампы, подписи, надписи на экранах и вывесках.
- Сохраняй исходный язык текста; каждый логический блок текста — с новой строки.
- Если текста на картинке нет (фото, мем, скриншот без надписей) — напиши одну строку «текста нет».
- Неразборчивые места помечай «(неразборчиво)»; не восстанавливай и не додумывай текст.
- Ничего не выдумывай и не поясняй, что изображено.

ФОРМАТ ВЫВОДА (строго): обычный текст без markdown (без звёздочек, решёток, тегов): строка «Картинка N:» с новой строки, под ней — распознанный текст этой картинки.

Ответ:

<!-- ==== ДОКУМЕНТЫ ==== -->
К тебе приложены {count} документ(ов).

Для каждого документа по порядку:
- Сделай детальный конспект содержимого: о чём документ, основные темы и факты.
- Перепиши точно ключевые данные: даты, числа и суммы, имена, названия компаний и проектов, ссылки, контакты, условия.
- Если документ не содержит полезной информации — напиши одну строку «без полезного содержимого».
- Ничего не выдумывай; если данные неполные — помечай «(данных мало)».
- Пиши по-русски, обычным текстом без markdown (без звёздочек, решёток, тегов), формат: строка «Документ N:» с новой строки, затем конспект.

Ответ:

<!-- ==== ТАБЛИЦЫ ==== -->
Ниже — фрагмент {i}/{n} электронной таблицы ({source}). Каждая строка — строка листа,
колонки разделены « | ». Смысл колонок поясняет строка «КОЛОНКИ:» (в начале листа
и периодически по мере текста). Префикс «[Лист N]» — имя листа книги.

Сделай конспект фрагмента таблицы:
- О чём таблица: листы, категории и разделы, какие позиции представлены.
- Ключевые факты переноси точно: названия, коды, цены и скидки, акции и их условия (например, «цена при заказе на сумму»), диапазоны значений.
- Однотипные строки (прайсовые позиции) не пересказывай построчно: сгруппируй по категориям/разделам и дай сводку — сколько позиций, типичный диапазон цен; отдельно выдели новинки и акционные позиции с их ценами.
- Повторяющиеся заголовки колонок («КОЛОНКИ:») — служебные, в конспект не включай.
- Точные числа, коды и названия переноси как есть — не округляй и не приукрашивай.
- Ничего не выдумывай; неполные данные помечай «(данных мало)».

ФОРМАТ ВЫВОДА (строго): обычный текст для чтения в txt, без markdown
(без звёздочек, решёток, обратных апострофов, html-тегов).
Никаких emoji и markdown-таблиц (строк с вертикальными чертами |): перечисления — только через дефис «- ».
Тему обозначай строкой-заголовком с новой строки, например: ТЕМА: Новинки каталога.
Перечисления — через дефис «- » с новой строки. По-русски, только конкретика, без воды.
